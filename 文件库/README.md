# Lantern File Manager

一个可通过局域网浏览器访问的多用户文件管理器。`openwain` 保留为公用账户，其文件位于 `storage/`；个人账户的文件位于 `data/users/<用户名>/files/`，彼此不可访问。

## 启动

1. 在 `config.json` 中配置公用账户，在 `xyy_password.txt` 中按 `用户名:密码` 每行一个的格式管理个人账户。用户名支持中文，但不能使用 Windows 文件名禁止字符。
2. 在本目录运行：

   ```powershell
   npm start
   ```

3. 本机打开 `http://localhost:8787`。局域网其他设备打开终端显示的地址。

首次登录需要输入用户名、密码和验证码。登录成功后，浏览器会保留一年的安全登录态；可在界面右上角退出。

个人账户首次成功登录时才会创建独立文件目录与回收站。修改 `xyy_password.txt` 后需重启服务。
服务启动时会检查用户名冲突：英文大小写、全角/半角或 Unicode 组合形式规范化后相同的名称不允许同时存在，以防止共用同一存储目录。

通过 `xyy_password.txt` 登录的个人用户，可使用页首的工作区切换按钮一键进入 `openwain` 公共工作区，再一键返回自己的个人工作区。进入后文件浏览、上传、下载、重命名、删除和回收站权限均与 `openwain` 相同；由个人用户上传到公共工作区的文件会显示真实上传者，记录保存在 `data/upload-attributions.json`。

默认情况下，同一 IP 地址在 15 分钟内连续失败 5 次后会被临时限制登录；可在 `config.json` 通过 `maxLoginAttempts` 和 `loginWindowMinutes` 调整。验证码与请求 IP 绑定且仅能使用一次。

“最近修改”最多扫描 2,000 个项目并展示其中最新的 200 项，以避免大文件库打开页面时卡顿；可用 `recentScanLimit` 调整扫描上限。

回收站默认保留 30 天，服务启动时会自动清理过期内容；可用 `trashRetentionDays` 调整。`data/audit.json` 会保留最近 2,000 条登录、上传、删除、恢复和分享操作记录。

全库搜索默认扫描最多 5,000 个项目并返回前 200 条匹配项，可用 `searchScanLimit` 调整。

## 文件分享

- 个人账户可将自己的文件发送给其他个人账户；`openwain` 不参与个人分享。
- 分享只在 `data/shares.json` 中创建访问标记，不复制或移动源文件。
- 收到的文件同时出现在根目录“全部文件”和“收到的文件”中，可下载、删除访问标记或继续转发。
- 源文件进入回收站后分享会显示不可用；恢复后会自动恢复访问。

## 安全提示

- 该服务默认监听局域网地址。不要直接将端口暴露到互联网。
- 请务必替换 `config.json` 内的默认密码，并使用强密码。
- 若需公网访问，请置于 HTTPS 反向代理或 VPN 后面。

## 仅本机测试

下列命令会临时只监听本机，不影响 `config.json`：

```powershell
$env:LANTERN_HOST='127.0.0.1'; $env:LANTERN_PORT='8788'; npm start
```
